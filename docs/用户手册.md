# 用户手册

## 1. 软件简介
本程序是一个用 C++ 模拟的 ROS 发布—订阅通信系统。它模拟了机器人框架中「传感器发布数据、显示器/记录器接收数据」的完整流程，不需要安装真实 ROS。

## 2. 运行环境
- 操作系统：Windows / Linux / macOS
- 编译器：支持 C++17 的 g++、Clang 或 MSVC
- 无需额外第三方库

## 3. 编译步骤

### 3.1 Linux / macOS（命令行）
1. 打开终端，进入项目根目录 `ros_sim/`。
2. 执行编译命令：
   ```bash
   g++ -std=c++17 -pthread src/main.cpp src/ros_core.cpp \
       src/publisher.cpp src/subscriber.cpp src/logger.cpp -o ros_sim
   ```
3. 运行：
   ```bash
   ./ros_sim
   ```

### 3.2 Windows（Visual Studio）
1. 新建「空项目」，把 `src/` 下所有 `.h`、`.cpp` 添加到项目。
2. 项目属性 → C/C++ → 命令行，附加选项填写 `/utf-8`。
3. 项目属性 → C/C++ → 常规，将「SDL 检查」设为「否」。
4. 在所有头文件包含之前加入：
   ```cpp
   #define _CRT_SECURE_NO_WARNINGS
   ```
5. 按 F5 编译运行。
6. 如果编译失败请将test_case转为从生成中排除

### 3.3 CMake 方式
```bash
mkdir build && cd build
cmake ..
make        # Windows 下用 cmake --build .
./ros_sim
```

## 4. 程序演示内容
主程序依次运行三个场景：

### 场景一：基础字符串消息
- 发布者 `pub_sensor` 向话题 `/sensor/temp` 发送两条温度消息。
- 订阅者 `sub_display`、`sub_logger` 同时收到并打印。

### 场景二：温湿度复合消息
- 发布者 `pub_env` 向话题 `/env/data` 发送两条含温度、湿度的传感器消息。
- 订阅者 `sub_monitor`、`sub_alert` 接收并打印。

### 场景三：异常边界测试
依次触发并捕获：
1. 空节点名；
2. 重复节点名；
3. 空话题；
4. 空消息；
5. 向不存在的话题发消息（仅警告，不崩溃）。

## 5. 日志说明
- 控制台按时间打印 INFO / WARN / ERROR 三级日志。
- 同时写入 `logs/ros_sim.log`，可用于事后排查。
- 日志格式：`[时间] [级别] 消息内容`。

## 6. 运行测试用例
```bash
g++ -std=c++17 -pthread src/test_cases.cpp src/ros_core.cpp \
    src/publisher.cpp src/subscriber.cpp src/logger.cpp -o test_cases
./test_cases
```
测试结束后输出 `X passed, 0 failed` 即表示全部通过。

## 7. 常见问题

### Q1：编译报 `localtime` 不安全（C4996）
在源文件最顶部、所有 include 之前加：
```cpp
#define _CRT_SECURE_NO_WARNINGS
```
或把 `localtime` 替换为 `localtime_s`。

### Q2：中文注释/日志出现乱码
将源文件另存为「UTF-8 带签名」编码，并在项目命令行选项中加入 `/utf-8`。

### Q3：日志文件没有生成
确认程序运行目录下存在 `logs/` 文件夹；程序会自动创建目录。若使用 IDE，检查工作目录设置。

### Q4：想新增一个话题或节点
参照 `main.cpp` 中场景写法：创建 `Publisher` 或 `Subscriber` → 调用 `init()` 注册 → 调用发布方法即可。
