# 技术文档

## 1. 开发环境
- 语言标准：C++17
- 编译器：g++ 7+ / MSVC 2019+ / Clang
- 构建工具：CMake 3.10+（可选），或直接 g++ 命令行
- 依赖：仅标准库（iostream、memory、mutex、thread、chrono、ctime、map、vector、set、fstream、filesystem）

## 3. 关键实现说明

### 3.1 单例实现（ROSCore）
采用「双检锁 + 互斥锁」懒汉式单例：
- 静态私有指针 `instance`；
- `getInstance()` 首次加锁创建；
- 拷贝构造与赋值运算符 `delete`，禁止复制。

### 3.2 节点共享所有权
Node 继承 `std::enable_shared_from_this<Node>`，使节点在 `init()` 中能通过 `shared_from_this()` 把自身安全地注册到核心，避免悬垂指针。核心用 `shared_ptr<Node>` 持有全部节点。

### 3.3 时间戳生成
使用 `std::chrono::system_clock::now()` 获取当前时间，`std::strftime` 格式化为 `YYYY-MM-DD HH:MM:SS`。
- Linux/g++：`localtime`
- MSVC：建议替换为 `localtime_s`（代码中 Logger 与 Message 可按需调整）。

### 3.4 消息多态
`Message::serialize()` 为虚函数；`SensorMessage` 重写该方法，输出温度与湿度。核心转发时不关心具体消息类型，订阅者通过基类接口读取。

### 3.5 日志分级
`LogLevel` 枚举定义 INFO / WARN / ERROR：
- INFO、WARN 输出到 `std::cout`；
- ERROR 输出到 `std::cerr`；
- 同时追加写入日志文件并 `flush` 保证落盘。

## 4. 编译方式

### 4.1 命令行 g++
```bash
cd ros_sim
g++ -std=c++17 -pthread src/main.cpp src/ros_core.cpp \
    src/publisher.cpp src/subscriber.cpp src/logger.cpp -o ros_sim
./ros_sim
```

### 4.2 CMake
```bash
cd ros_sim
mkdir build && cd build
cmake ..
make
./ros_sim
```

### 4.3 运行测试
```bash
g++ -std=c++17 -pthread src/test_cases.cpp src/ros_core.cpp \
    src/publisher.cpp src/subscriber.cpp src/logger.cpp -o test_cases
./test_cases
```

## 5. 已知限制与扩展方向
- 当前消息转发为同步调用；可扩展为每个订阅者独立线程队列，实现真正异步。
- 未实现服务（Service）一问一答通信；可新增 ServiceServer / ServiceClient 类。
- 未实现节点动态注销；可在核心增加 `unregisterNode()` 方法。
- 消息类型目前为字符串与温湿度；可扩展为序列化/反序列化框架。
